# Siege Draft interface

Preserve the static HTML/CSS/JavaScript stack and historical scoring formula. The screen's job is to compose two teams and compare the next modeled pick.

Use charcoal surfaces, orange Attack accents, teal Defense accents, restrained borders, and system fonts. Show five team slots, readable operator names, and explicit unmodeled labels. Use native buttons for tap/keyboard selection while retaining drag-and-drop. Keep search and opposing-team randomization visible. Confirm resets.

On phones, stack the teams and bound each roster to a scrollable, keyboard-focusable region so recommendations remain reachable. Use visible focus rings, labeled controls, live status messages, reduced-motion support, and 44px control targets. Keep loading, model failure, no search results, empty draft, and full-team states explicit.

References: the existing Siege Draft interface and operator icon system. No external brand template or new runtime dependencies.
